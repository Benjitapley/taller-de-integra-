### Comando preparado para ejecutar con la credencial vigente

Este bloque está preparado; **no consta una ejecución SQL exitosa**. Desde la
raíz `taller-de-integra-dos/roomies-web`, en PowerShell:

```powershell
$pgCredential = Get-Credential -UserName postgres -Message 'PostgreSQL local de pruebas'
$pgEncodedPassword = [Uri]::EscapeDataString($pgCredential.GetNetworkCredential().Password)
$env:CONVIVENCIA_TEST_SERVER_DSN = "postgresql://postgres:${pgEncodedPassword}@127.0.0.1:5432/postgres"
# Solo si el rol sql_convivencia_mensajeria ya existe, configurar también su
# CONVIVENCIA_DATABASE_URL con la contraseña vigente y la base de pruebas.
try {
    python backend/services/convivencia-mensajeria-service/tests/run_local.py
    if ($LASTEXITCODE -ne 0) { throw 'La suite SQL no terminó correctamente.' }
} finally {
    Remove-Item Env:CONVIVENCIA_TEST_SERVER_DSN -ErrorAction SilentlyContinue
    Remove-Variable pgCredential, pgEncodedPassword -ErrorAction SilentlyContinue
}
```

La suite existente usa PostgreSQL real para invariantes y concurrencia, pero
inyecta dobles HTTP de Identidad/Publicaciones y mocks en pruebas de contrato.
Aunque termine verde, no sustituye el recorrido integrado sin mocks solicitado.

## Cambios realizados

- Gateway: permite GET de integrantes y conserva query/cursor; prueba específica
  de destino, sesión, query y ausencia de cabecera interna reenviada.
- BFF: integrantes funciona independientemente de `WEB_REPORTES_ENABLED`,
  valida `limite` 1–100 y admite hasta ese tamaño; conserva 403/404/503 y
  elimina campos privados de cada integrante. Se restauró además el control
  de habilitación de Reportes en su propio handler, detectado por la suite.
- Frontend: [useActiveRental](../frontend-next/src/features/convivencia/useActiveRental.ts)
  centraliza la consulta sin caché, revalidación, validación de cupos, cancelación,
  limpieza y reintento. Lo usan Mi arriendo y el gate de contenido privado.
- La validación del servidor se complementa con un gate cliente que vuelve a
  comprobar pertenencia y desmonta Chat/Tareas tras pérdida de acceso.
- Los previews requieren `NEXT_PUBLIC_ROOMIES_VISUAL_REVIEW=true` explícito y
  modo desarrollo; el ejemplo de entorno lo deja en `false`.
- Runner PostgreSQL local seguro descrito arriba. No se modificaron migraciones
  ni datos de negocio para hacer pasar pruebas.
