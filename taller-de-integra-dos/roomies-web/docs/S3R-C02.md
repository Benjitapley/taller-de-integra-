## Resultado

Listado expone el DTO canónico, detalle público, catálogo y publicaciones propias
con cursor firmado y consulta keyset. El filtro de disponibilidad usa igualdad
sobre ocupación confirmada y conserva la alternativa mínima de transición.

región/comuna validada. La web ofrece comunas de La Araucanía.

Las fotos usan el bucket `publicaciones`, con referencias de negocio en Listado,
validación real, conservación/orden, journal de reintentos y limpieza persistente.
Permisos, replay y control de versión impiden mezclar propietarios o borrar la foto
de una edición concurrente ganadora. Cerrar conserva las imágenes.

La web adopta el envelope/cursor, carga más con reintento y sin duplicar filas,
acepta múltiples archivos y conserva selecciones si falla el guardado. BFF,
Gateway y servicio admiten el máximo multipart válido de cinco archivos de
5 000 000 bytes. El adaptador HTTP de Match conserva su respuesta de transición.
